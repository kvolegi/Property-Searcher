# Правила для контриб'юторів (Contributing) 🛠️

Цей проєкт є авторською розробкою **kvolegi**. Якщо ви бажаєте запропонувати виправлення чи додати підтримку нових джерел моніторингу:

1. **Telegram HTML розмітка:** Усі повідомлення бота відправляються у форматі `HTML`. Обов'язково екрануйте будь-які сторонні символи (`<`, `>`, `&`), щоб Telegram API не повертав помилку 400.
2. **Безпечні паузи (Rate Limiting):** Не зменшуйте інтервали опитування нижче безпечних (600 мс між запитами та базовий цикл), щоб джерела не блокували IP-адресу користувача.
3. **Робота з налаштуваннями:** Для читання й запису файлу конфігурацій використовуйте виключно `SettingsManager`.
4. **Pull Requests:** Створюйте окрему гілку для вашої зміни та коротко опишіть, що саме було оптимізовано або виправлено.
