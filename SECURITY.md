| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

Security is a fundamental priority for the Property Searcher platform. If you discover a security vulnerability or sensitive information exposure:

1. **Do not create a public issue**: Please refrain from posting details of suspected vulnerabilities in public GitHub issues, pull requests, or forums.
2. **Contact the Maintainer**:
   - Open a private security advisory on GitHub: [Security Advisory](https://github.com/kvolegi/Property-Searcher/security/advisories/new)
   - Or reach out via Telegram: [@Property_Searcher_bot](https://t.me/Property_Searcher_bot)
3. **Report Contents**:
   - Detailed description of the vulnerability and attack vector.
   - Proof of Concept (PoC) or step-by-step reproduction instructions.
   - Component affected (`core-desktop`, `enterprise-backend`, or API).
   - Any proposed remediation or mitigation strategy.

### Response Timeline
- **Initial Acknowledgement**: Within 24–48 hours.
- **Triage & Status Update**: Within 72 hours.
- **Fix & Advisory Release**: Coordinated with the reporter prior to public disclosure.
